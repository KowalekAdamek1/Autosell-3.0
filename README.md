# Mod na Gencasha (Fabric)

## Funkcje
- **Mod na Gencasha (AFK)**: kopanie obszarowe **3x3, 5x5, 7x7, 9x9, 10x10** z regulacją zasięgu (`range`) i szybkości (`delay`).
- **AutoFood**: automatyczne jedzenie z offhandu po spadku głodu do ustawionego progu (domyślnie `7`).
- **Swing Animations**: przyspieszona i wyostrzona animacja machnięcia ręką.
- **Visuals**:
  - **Ore ESP**: pełne wypełnienie **3D Fill** zamiast ramek 2D.
  - **Tracers**: płynne linie z interpolacją pozycji rysowane od **środka celownika**.
  - **Player ESP & Nametags**: tryb **3D** oraz zachowany tryb **2D**.
- **GUI**: wyostrzony interfejs 1px pod klawiszem `Right Shift`.

## Budowanie `.jar` na GitHubie
Wrzuć zawartość paczki do repozytorium GitHub — workflow `.github/workflows/build.yml` automatycznie zbuduje plik `.jar` w zakładce **Actions**.
